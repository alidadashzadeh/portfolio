# Personal Portfolio

Modern developer portfolio built with Next.js, Tailwind CSS, and Framer Motion to showcase full-stack projects, technical skills, and interactive UI development.

## Live Demo

Portfolio: https://portfolio-alid.vercel.app/

## Features

- Responsive modern portfolio design
- Interactive project showcase section
- Animated UI transitions with Framer Motion
- Mobile-first responsive layout
- Optimized performance with Next.js App Router
- Project video previews and live demo links
- Reusable component architecture
- SEO-friendly page structure

## Tech Stack

### Frontend

- Next.js
- React
- Tailwind CSS
- Framer Motion
- shadcn/ui

## Project Structure

```bash
src/
├── app/
├── components/
├── constants/
├── data/
├── lib/
└── styles/
```

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 to view the project locally.

## Deployment

Deployed on Vercel.
